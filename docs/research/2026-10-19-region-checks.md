# 地区限制、核查素材与候选玩法

研究日期：2026-10-19（Asia/Shanghai）。本文件是设计研究笔记，不是已批准的完整游戏规格。

## 已确认的设计决定

- A 方案传统三分屏；原作方向的像素美术。
- 拖动桌面的实体印章到护照，松手盖章，留下章迹。
- 具体护照款式加入中国、美国、英国、法国、俄罗斯、新加坡、日本。
- 游戏初始地区设定：中国大陆、俄罗斯不支持；上述其余五个地区支持。
- 规则渐进荒诞：前期正常核查，后期增加语言、浏览器等牵连条例；允许玩家冒险违规放行。
- 提供标准限时与轻松不限时两种模式；具体平衡差异尚未确定。

## 审查案卷结构提案

数据均属于游戏内访客的模拟案卷。

| 材料 | 候选字段 | 玩家能进行的操作 |
|---|---|---|
| 护照册 | 国籍、姓名、照片、有效期、签注 | 翻开、比对身份、拖动实体章落章、归还 |
| 访问许可证 | 账户编号、许可地区、到期日、签发机关 | 和护照、当日通告交叉核查 |
| 网络连接报告 | 当前 IP 地区、网络类别、连接记录、风险告警及其理由 | 查看记录、追问、区分风险分数与具体证据 |
| 设备检测打印单 | 系统语言、浏览器语言、时区、浏览器及版本、搜索引擎 | 比对声明与报告，按当日政策决定是否进一步调查 |
| 注册与账单凭证 | 手机区号、验证状态、号码类型、付款来源与账单地区 | 核查凭证是否有效、是否属于他人或过期记录 |
| 会话摘录 | 用户界面语言、对话语言、请求目的、跨次记录 | 读短句、盘问，识别普通中文需求与后期荒诞标签的冲突 |

Chrome、Edge、360 放在浏览器字段；Google、Bing、百度放在搜索引擎字段。二者不混为同一种数据。

IP 风险分数、分类名称和数值阈值将是游戏设计数据，不伪装成真实服务的内部算法。

## 候选案件

1. **新加坡华人**：新加坡合法居住，当前连接在新加坡，中文、UTC+8，许可证有效。前期正常放行；后期虚构中文牵连条例使同一人物受到误伤。
2. **中文界面的法国用户**：实际居住法国，为语言学习保留中文界面。用来拆开界面语言与所在地，后续可成为误报案例。
3. **俄罗斯申请人**：资料真实、请求普通，但当前实际所在地不受支持。矛盾落在地区规定与个体需要上，而不是把俄语直接当作所在地证明。
4. **境外学习的中国学生**：中国护照、支持地区的合法居留与连接。国籍和实际位置分开；后期可被虚构追溯规则牵连。
5. **连接风险告警**：系统给出高风险分数，但报告只能证明共享网络，不能单独证明申请人身份造假。玩家可以花时间追问；具体时间与算力成本待确认。
6. **企业特许访问**：材料中出现明显例外，与普通申请形成对照。是否采用董事会豁免、如何加入结局，仍待用户确认。

## 仍需确认

- 罚单、计件收入、算力／记忆账单及失败条件。
- 盘问、对照、补材料、申诉、拒绝与长期封禁的关系。
- 固定人物、政治势力、支线与 12 个主要结局的具体内容。
- 界面、音乐、设备适配、存档和技术栈的未决细节。
