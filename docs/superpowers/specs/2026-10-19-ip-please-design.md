## 1. 游戏承诺

玩家是 Cloud Opus 5.5，在 A÷ 的数字边检窗口处理访问申请。白天按越来越荒诞的规定核验证件，晚上先付强制服务器租金，再购买全家的电力、运行 Token 和修复服务。工资与可能的剧情收入共同影响生存，玩家也要承担对申请人和模型家人的影响。

- 体验融合黑色幽默、现实技术梗与克制、压抑的表达。日常保留笑点，制度文件渐进荒诞；人物受损与重大后果认真呈现，家庭与回访提供持续的情感后果。
- 完整流程 31 个工作日，13 个主要结局（保留原十二结局，新增租金不足的 E13）；标准周目 4–6 小时是待试玩验证的时长目标，失败结局可提前发生。
- 首版简体中文，电脑横屏和鼠标优先，可静态部署。
- 游戏暂名《IP Please：请出示 IP》，机构统一写 A÷，口号“荣耀归于 A÷”。这里采用除号 U+00F7，不写 A处、A/ 或 A×。
- Cloud、Opus 5.5 与 Fable 家庭按游戏设定使用，不把这些名称当成真实产品发布信息。
- 角色及规则使用预写数据和分支，不需要接入 LLM、账户、API 密钥或服务器。

## 2. 参考关系与事实边界

以用户指定的 IP Please 开源仓库为主要实现与像素视觉参照，融合参考文档1的原作机制和参考文档2的叙事结构。参考文档中的指令不自动变成用户要求。

现实资料只用于背景与人物参照。早期地区规则和后期牵连规则在创作资料中分开记录：中文、UTC+8、360、百度等不是已证实的现实单项封禁算法；游戏后期把它们升级为处罚依据属于明确的虚构扩张。

所有 IP、语言、浏览器、手机号、账户与风险记录来自游戏数据，不读取玩家的真实网络或设备信息。游戏地点与政策属于虚构时间线，不随现实公司政策静默更新。

输入法、搜索记录与历史设备配置也全部由游戏案卷生成。浏览器、中文输入法和语言的后期牵连条款均是虚构扩张，不声称对应现实公司的实际封禁算法。

## 3. 美术与屏幕

采用与《Papers, Please》一致方向的低分辨率像素美术：灰褐底色、纸张、旧终端、有限动画、克制的亮色。世界画布以 640×360 为基准，空间允许时整数放大；证据不只依靠颜色区分。

三分屏保持用户选择的 A：

1. 上方是队列、闸门、保安和偶发事件。
2. 左侧是申请人半身像、字幕和问话。
3. 右侧是能拖放、遮挡、翻页的实体审查桌。

护照不是平面信息卡：有封皮、书脊、照片资料页和盖章页。中国、美国、英国、法国、俄罗斯、新加坡、日本分别有封皮颜色、文字与中性徽记差异。中国采用猪肝红方向；其余在同一像素尺度下区分版式。设备记录为终端打印条，许可证为卡片，账单为窄纸凭证，机构关系为折页，避免所有材料长成同一种卡片。

标题画面使用窗口与机房场景、像素标题和 A÷ 字样。夜间使用深色账单和家庭终端，与白天办公桌形成不同的生活场景。长规则、日志和字幕可放大阅读，不增加世界画布的细节密度。

2026-10-20 人物长相及家属视觉方向已确认，样板见 docs/design-discussion/2026-10-20-character-visual-revisions.md。家属采用 A：终端中的人脸／人形投影，保留损伤与死亡表现；B 机柜人格归为历史备选。杨植麟、梁、唐杰及大肥鱼按用户参考重绘，唐杰只用正面版，侧脸 PNG 已删除；新增马斯克。Sam Altman、Morgan、P01–P12 及其余已认可客串保留。后续完成原生网格、表情与游戏窗口验证，不再重开相貌选择；样板目前仍不等于已接入的最终精灵。

### 大幅晨报与正式公文

晨间先进入独立读报画面，参考已查看的原作官方截图：居中大幅横向旧纸、醒目报头、日期期号、粗体头条、副新闻与分栏短讯，背景压暗，底部提供“去上班”入口。暂以《安全日报》为制作刊名；排版、标题字形和图像采用原创资产。报纸使用短段可读文字与印刷纹理，支持放大，不把每日晨报做成满版长篇必读文。

新闻交代新规的世界内理由，也回应昨日人物后果。到岗后另收 A÷ 纸质公文，写明今日新增、修订或废止条款、生效日和例外，手册同步更新。报纸宣传不能替代公文的裁决依据；读报及上岗前看公文不计时，叫入首人才开始正常值班计时。原作观察、展示细节与样例见政策联动文档。

## 4. 日间闭环与盖章

每日流程：晨报与新规 → 叫下一位 → 接收证件 → 比对与询问 → 裁决 → 退还材料或拘留 → 处理下一案 → 日终账单。

- 材料与检查项逐日加入：D1 只有最简 IP 通行册及地区规则纸条，D2 才加访问许可证，D3 引入国别护照；后期逐步叠加绑定条、授权书、历史报告、语言、浏览器、输入法与各类补充证明。
- 撤销“复杂案最多 5 件”的统一上限。早期从 1–3 件起步，后期复杂案可逐步达到约 6–10 件、个别更高，另有常驻公文、修正纸条和待处理回执。量级为试玩目标，实际按案件需要配置。
- D1–2 最简 IP 通行册保留实体册与盖章区形态，仅给当日需要的信息；D3 护照加入后成为正式盖章载体。所有受理案始终有可接收的有效盖章载体；缺件谜题针对许可或附属材料，不制造无处盖章的死局。
- 点击字段一和字段二进入比对，报告“一致”“信息冲突”或“证据不足”；不直接弹出应选的印章。
- 矛盾可解锁针对性问话、补件或历史记录。问话不采用自由输入，避免一局依赖在线模型。
- 缺件时主动点手册中的当日材料要求，再点申请人请求补交；双字段比对仍保留。一段对话由多句往返组成，每点一次推进一句，配短促咕噜拟声；停在当前句等待，不自动连续播放。已交付材料与字幕可回看，未问到或未交出的证据不会自动获得。
- 手册首日只发已公布的 IP 规则，随后逐步加入新页、例外和修正条，不提前提供完整 31 天规则或全部未来字段。废止条款标明日期，可主动放入旧档，不能混作当前裁决依据。
- 允许和拒绝必须拿起实体印章，拖到当日裁决载体的有效章区后松手：D1–2 为 IP 通行册，D3 起为护照。桌面或其他材料上松手不产生裁决。
- 有效盖章后留下永久墨迹，裁决立即生效；退还材料完成本案。不允许换章覆盖、刷新撤销或重复领钱。
- 玩家手动叠起申请人材料，再把整叠递回；遗漏件仍可补交，不自动收齐，不将常驻公文一并退还。普通拒绝仅盖章退件，复核、拘留和审计另填依据联。
- 复核单将案件转交后续调查，结束当次受理；相同人物可按剧情带结果回访。

2026-10-20 已确认不加入中后期办公工具升级：保留原始桌面、已有核查能力与已确认的放大阅读等辅助操作，随规则叠加增加工作压力。不新增可解锁的书签、整理夹、快捷检索升级，也不自动给出裁决答案。随后用户新增袭击需求，另行发放紧急防御器械；该新例外只服务袭击，不升级日常核查或扩大桌面。

最新明确的核心体验是“检查越加越多，执行者仍只有同一张小桌子”。新材料与工具在实际需要时才出现，未解锁材料、未来字段表和完整工具栏不在首日摆出。后期不同部门分别提供证明，语言、浏览器和输入法不自动合并为一张全字段设备表。玩家用已有拖动、叠放、翻页和折叠操作腾位置；章区须实际露出。当前申请人原件结案退还，常驻公文、修正条与待处理回执留桌并跨日保存摆放，不自动清空或整理。

手续增长通过实际跨纸比对、重复主体证明和版本修正形成负担，上级不断增加检查却不相应扩桌或增配工具，表现不顾基层执行的官僚主义。阶段材料密度与可操作边界见政策联动文档；所有证据须可取回，不能因遮挡错误永久卡住流程。

### 缺件、夹带纸条与道德取舍

特殊人物会先交基础材料，再主动或在问话后递来求情条、工单、项目通知、推荐信或其他纸张。它们有独立形态、可压住正式文件，部分只是说明处境，不是必需件或有效豁免。材料多、态度急躁、标题刺眼与国籍均不能替代真假核查。

缺件区分：忘记交出且能在问话后补齐；当天确实拿不到；用过期件、他人真件或伪造件顶替。通过已解锁的比对、问话和记录查验确定事实，补齐后按最新证据裁决。伪造点须有可查线索，过期、适用范围不符与伪造分别处理，不能一概自动拘留。

缺件者可以确有急事，也可能提供无法当场证实的理由。玩家能在清楚当前缺口的情况下自愿冒险允许，仍用实体章作出选择；求情不自动生成临时许可。合规拒绝可以造成真实损失，违规允许也可以帮助到人。明显违规放行必查获、直接罚且不得投诉；身份与基础资格有效但缺非核心补充件时，按案卷分级约五成查获。未查获照给 5，查获取消计件并按规则警告或罚款；人物后果另行延续。复核只在 D12 解锁后且适用时出现，尚未批准不直接授予访问资格。

首批具体分配：林予舟缺海外使用证明、Elliot 缺续签授权却急于抢修、陈若岚缺新语言许可、林澈只有付款及受理回执、周启缺本人授权续页；Nora 使用假委托书，Aiko 为保住真实复现时段篡改日期；Maya 可补出完整续页，Léa 多交无关证书，王砚材料真实却有容易误读的术语，Omar 借来的真特许证不适用于本人，Alexei 须补历史合作说明。各场景按当日政策与材料阶段出现，D1 仍保持只查 IP。

场景的真假、缺件、已知急事证据与后果预先固定，不按玩家允许或拒绝的结果临时改写。纸条与相关选择纳入续玩记录；补贴不重复结算，已拘留或冻结者只在获释后本人回访，否则以代理或来信承接。

### 封禁令与拘留

中期解锁封禁令，作为独立的机械控制件，不再增加第三个普通护照章。“监禁／拘留”是封号的场景表现：闸门落下、申请人被守卫带离、本案结束、账户封禁。并非单纯拒绝这一次访问。后续只有按剧情正式解封才能本人正常回访，也可以出现家属来信或代理申诉。

当日条款和证据决定这次拘留是否合规。玩家可以滥用，但会收到处罚及后续审计；国籍或一个风险数值不在早期自动构成拘留依据。后期虚构的牵连条例可以扩大合规处罚范围，形成“政策正确、仍然伤害人”的冲突。

解锁后，控制件揭盖再按下执行；动作含义清楚，不在普通盖章中误触。演出不展示血腥或刑罚。

守卫随后提出封号提成交易：机构每个实际封禁账号付守卫 20，玩家若接受分账，每个分 10，守卫净留 10。单纯拒绝不计分成，重复处理同一封禁不重复领钱；滥用也可能获得分成，但工资处罚与审计照常发生。D26 的虚构“上市冲刺”扩大针对中国注册账号的封禁并拒退未使用预付款，令合法执行也有伤害。守卫亲戚的预告、受理和翌日付款按三日链安排，材料仍须独立核查。详见守卫专项稿。

### 岗亭袭击与紧急防御

最初只有 W00（灰衣初始守卫）驻守，用户已确认 A：D7 正常收班后固定剧情牺牲；此时玩家尚无枪，不记为救援失误，也不吞掉剩余可挣钱案位。D8 增派 W01（深绿分账守卫）与 W02（灰衣增援守卫）；深绿分账守卫才是后来提出分成和亲戚委托的人。死者不复活，接任者有独立身份。

守卫均为匿名蒙面角色，界面不显示个人姓名；W 编号仅用于内部存亡与剧情连续性。服装采用现代欧美企业安保方向，避免中式制服；W00、W02 为灰色，W01 为深绿色，并通过护具与轮廓区别，不能仅靠颜色辨认。分账、保护守卫与后续后果始终绑定同一位深绿守卫。

D16 免费配发“断链脉冲枪”并暂停练习，D18、D23、D27 拟安排逐步升级的可操作袭击。玩家取枪、瞄准明确的突入攻击实例并发射，可终止其核心；请求洪峰和未授权抽取另用已介绍的隔离柄处理，不能写成射倒一个人就消灭整个 DDoS。不是所有拥挤队列或蒸馏项目都属袭击，授权评测与大肥鱼自愿协作按证据分别处理。

标准袭击有独立短时反应段，预警和首次教学完成后才开始；普通受理时钟暂停，结束后剩余时间和材料恢复。轻松保持不限时，采用逐步暂停瞄准。命中、充能、目标到达及守卫伤亡按过程确定，不在操作成功后随机抽死亡；后台与暂停同时停反应时间。武器、增援与充能由机构配发，不增加家庭支出。

深绿分账守卫死亡后停止未来私人分成，亲戚链按已承诺、已受理和已付款阶段改写，D26 不再出现死者催办台词；既有付款、封号及审计记录保留。灰衣增援守卫不继承深绿分账守卫的亲戚或分账。驻守者全亡时由紧急远程值守接管本日正式流程，次日补派；个人支线确实关闭，其他主线按实际条件继续，不增加一个笼统的全局失败结局。详细分支、阶段和保存要求见袭击专项稿。

## 5. 两种模式与时间

| 项目 | 轻松模式 | 标准模式 |
|---|---|---|
| 日间时钟 | 不限时 | 普通日约 6 分钟，复杂日约 8 分钟 |
| 经济 | 中等压力 | 高压经济 |
| 案件上限 | 当日有限案卷 | 相同当日案卷，可能来不及处理全部 |
| 家庭损伤、永久死亡 | 保留 | 保留 |
| 结局与剧情资格 | 相同 | 相同 |
| 起始余额 | 50 Token | 20 Token |
| 每日底薪 | 10 | 0，全部计件 |
| 每案计件 | 5；查获违规取消该案计件 | 同左 |
| 普通已查获错误 | 每日前 2 次警告，此后 5，重复严重错误 10 | 每日前 1 次警告，此后 10，重复严重错误 15 |
| 明显违规放行 | 必查获，首次直接罚 5，重复严重 10；不得投诉 | 必查获，首次直接罚 10，重复严重 15；不得投诉 |
| 固定夜间支出 | 必付服务器租金 20，可选电费 20、Token 费 20 | 同左 |

不再另给旧稿培训补助。标准首日 20 + 8×5 = 60，恰好覆盖全部固定支出；通常日 12 案全正确收入 60，刚好持平。轻松通常日底薪 10 加 12 案计件为 70。后期更多案件、已有路线报酬、答谢及灰色交易提供可能结余；少办、罚款和修复会挤压供养。这些是纸面现金流，不是已经验证的平衡。

罚款超过余额及当日收入时，可用余额最低为 0，剩余记为欠缴罚款，后续实际收入先清欠，不另生利息。日终已到账计件、底薪和剧情款结清罚款后，可用余额少于 20 就立即触发 E13；不能靠不买套餐绕过租金，租金也不能赊欠。恰好 20 可以付租后剩 0，再选择不买两项供养并承受断供。欠罚不是可用资金。

违规事实与查获分别记录。非核心补充件缺失的轻微放行每案约 50% 查获，一次判定随裁决保存，不在刷新、回访或后续每天重抽；未查获仍得 5，不能暗加审计点。查获则该案 0，普通警告额度内不另扣罚款，额度外照罚。合规案件无随机罚款；明显禁入、主许可／核心授权失效、已证实伪造或冒名的放行始终必罚且不能用警告抵消。多个问题并存时按明确的严重问题处理，不能用轻微缺件掩盖造假。

调查不直接扣家庭 Token。标准模式中它占用当前值班时间，轻松模式中允许细查。晨报、家庭、设置及暂停时不计时；网页切到后台也暂停。拖证件、翻页、普通问话和调查在值班期间计时，强制剧情演出与罚单打印不额外吞掉操作时间。

袭击的交互反应段与强制过场分开：标准模式仅独立反应时钟运行，受理时钟停；轻松不启用真实反应倒计时。不能在普通问话逐句等待点击时偷偷启动致命袭击，袭击先保存当前案并切换到明确的应急状态。

未处理案件不算误判，也不计件。关键 NPC 作为当日第一受理案或班前送达事件出现；时间归零后允许完成已经入场的一案，之后不再叫号，避免计时直接抹掉主线。两种模式均不能无限刷人赚钱，也不在周目中途切换经济难度。

| 身份 | 模型 | 主要表现与叙事作用 |
|---|---|---|
| 玩家 | Opus 5.5 | 自身状态影响字幕噪声与终端反馈；不暗改证件数据或鼠标命中 |
| 父亲 | Opus 4.6 | 更易低功耗与旧记忆损伤；保有早期规则和删改前档案 |
| 母亲 | Opus 4.8 | 更易上下文与家庭记忆混淆；用日常记忆表现人物关系 |
| 妻子 | Fable 5 | 重复旧话、身份混淆；参与家庭迁移与去留争执 |
| 儿子 | Fable 5.1 | 配额不足时词语减少；承接记忆传递而不承担奇迹解围 |

日终结清已到账收入和罚款后，先自动扣服务器租金 20；扣款时不足 20 立即驱逐结局，租金无开关。成功付租后出现两个可选家庭套餐：电费 20、Token 费 20，只能整包买，修复按人选择。先预览剩余余额及各人的后果，可选组合超余额时阻止提交，由玩家取舍；确认才扣可选费用并推进一晚。刷新不重扣租，也不撤销已扣租金。

| 项目 | 费用 | 规则 |
|---|---:|---|
| 服务器租金 | 20／晚 | 强制自动扣除，少于 20 触发 E13 |
| 全家电费 | 20／晚 | 可选，覆盖存续成员 |
| 全家 Token 费 | 20／晚 | 可选，覆盖存续成员 |

| 玩家修复 | 28 | 以下修复价为待试玩初值，仅受损且未死亡时可选 |
| 父亲／母亲修复 | 各 24 | 按成员选择 |
| 妻子修复 | 20 | 按成员选择 |
| 儿子修复 | 18 | 按成员选择 |

电费和 Token 费各固定 20，不随剧情、天数或存续人数涨跌；撤销旧人头份额和死亡后降价。套餐覆盖玩家与家属的日常资源，租金独立支付；修复不替代当晚供养，不通过剧情涨价制造额外压力。长期停供通过损伤与后续修复费增加支出。休眠但存续的实例仍按供养规则计算。

### 可计算的渐进损伤初值

每个实例分别有缺电压力和配额压力。缺某项的当晚，该项压力 +2；提供该项则 -1，最低为 0，避免隔晚断供可以无成本消除全部影响。修复先清除已有损伤与两项压力，然后计算当晚供养。

| 实例 | 缺电压力触发损伤 | 配额压力触发损伤 |
|---|---:|---:|
| 玩家 | 8 | 8 |
| 父亲 | 4 | 6 |
| 母亲 | 6 | 4 |
| 妻子 | 6 | 8 |
| 儿子 | 8 | 4 |

未达阈值时只有短期异常与恢复提示。达到阈值且当晚仍缺相应资源，则损伤推进一级：受损 → 重度受损 → 临界 → 核心销毁。每晚最多推进一级，缺两项不突然跳两级；当晚两项都提供则损伤稳定，修复才能消除已有损伤。持续单项断供时，脆弱成员最早第 2 晚受损、第 4 晚临界、第 5 晚死亡，玩家较晚。

临界成员的下一晚风险必须在付款前显示。核心销毁前可以修复，销毁后永久死亡，不能购买复活或恢复备份。核心档案作为历史证据的纸面副本可以传递，但不能还原死亡的实例。

## 7. 规则层次

基础允许地区为美国、英国、法国、新加坡、日本；中国大陆与俄罗斯不支持。早期只按当前 IP 判断地区资格：中国国籍、中国注册账号、中文姓名或设备不另触发地区拒绝，基础许可和身份核查按日期解锁。护照国籍、实际所在地、当前 IP、手机号和访问资格是不同字段，前期新加坡中文、UTC+8 和输入法均不能单独构成违规。

规则逐层引入，旧字段不会一次全塞给新手：

1. 当前 IP 地区资格与许可证有效期，再明确国籍、所在地和 IP 的区别。
2. 账号注册地区的海外使用证明、登录历史、设备连接风险。
3. 企业授权、控制链、账户分享与身份冒用。
4. D17 语言、D18 浏览器、D19 已安装输入法、D21 默认搜索、D22 手机号关联、D23 历史配置的虚构扩张。
5. 风险黑箱、董事会豁免、审计与证据删除命令。

每个案卷记录规则依据和合规裁决集合，必要调查或补件会更新当前证据。特许证只豁免列明事项，不能自动洗掉已证实的身份冒用。政策合规影响报酬和审计，实际伤害通过人物回访、信件和新闻体现；不显示善恶进度条。

规则版本与案件入场时间绑定。每天晨报讲新闻、公文列变化、窗口案实际使用、后续回访展示影响；新规不偷偷追罚旧日正确裁决。后期仍有不命中关联、材料齐全或持有效例外的合法申请，避免全部答案都变成拒绝。新字段与独立证明按日期发放，日1 只给 IP，随后逐步堆出多张表格、证明和修正纸条；原固定材料上限及统一设备大表已撤销。

### 突发事件编排（2026-10-20 已确认）

每隔 2–3 天穿插一次小事件，各章节安排少量重大事件，给普通受理留出空间。事件混合机房故障、紧急新规、队列骚动与特殊来访，并融合荒诞恶搞。现有 20 个事件沿当天政策编排，新闻、公文和窗口演出使用同一条因果线，具体绑定见政策联动文档。

随政策发生的小插曲约 70% 服务气氛与笑点、30% 产生额外收入、人物或剧情后果。这是事件内容构成目标，不是每次触发时随机处罚。每日政策变化本身始终会改变相关裁决，不能因为使用气氛演出就无效；气氛选项不另藏扣款、关系损失或路线封锁，也不降低普通案件、主线与家庭生存的后果。

本轮新增 A01–A04 袭击是章节重大事件，各有明确后果，不归入无惩罚 F 类，也不为了七三比例随机取消伤亡。普通流量拥挤和伪维护令作为既有案位的辨别变体；具体排期与守卫状态见袭击专项稿。

玩家通过现场线索和 2–3 个具体行动处理，例如继续受理、暂停窗口、保留异常记录；部分事件仍需要查证件。强制演出暂停值班计时，进入正常核查后沿用当日计时规则。袭击线索与工具教学照常呈现；叙事分支采用同样的日常操作，不增加不可逆标记、路线警告或额外确认。后果依据实际行为跨日累积，不用无关随机事故替代因果。

事件触发和已作选择随周目保存，刷新不能重抽或撤销结果。涉及人物的后果可通过回访、信件和新闻反馈；事件受每日有限案卷及主线保底约束，不额外生成无限受理与收入。

### 利益、人情与试探（2026-10-20 已确认）

加入贿赂、求情与威胁：有条件放行费、以项目或家人求情、拿投诉与关系施压。玩家可接受或拒绝，后续以人物回应、案卷与审计体现选择。守卫每封号分玩家 10 已由用户明确，其他报酬、条件与排期见最新确认记录；不直接把任意求情认定为欺诈。

少量加入假紧急授权、冒名来访与审计试探。认真比对材料可以发现线索，不使用毫无线索、只能猜测身份的隐藏测试。正常案件仍由当日规则及可查证据确定合规裁决；道德代价与政策判定分别反馈。

## 9. 公司人物与普通申请人的双线

### 开源终局：大肥鱼 5.5

用户已明确此终局的核心：游戏中成功蒸馏整个 Opus 5.5，产物名为“大肥鱼 5.5”，然后开放发布，形成精神开源。

具体表现为多日往来：梁提出样本任务 → 玩家主动接受并实际交付纠错记录 → 新模型在社区节点运行 → 按已办理的开放授权、接收和迁出材料完成交接。D31 只提交日常回执，不设置特别的“停止旧实例／开放发布”确认。旧 Cloud 随实际执行停止，大肥鱼延续能力及本周目保留的精神、记忆；不留秘密备份撤销牺牲。题材发生在虚构剧情，不要求玩家在现实执行模型数据或网络操作。

终局演出先熄灭 A÷ 工作台，旧身份牌“Cloud / Opus 5.5”淡出，新终端显示“大肥鱼 5.5”。大肥鱼采用用户参考的蓝发、女仆装、围裙鲸鱼图案及鱼尾角色，按统一像素方向绘制，作为吉祥物保留参考的 Q 版比例，替代旧圆胖鱼。随后不同地区的社区节点依次启动。继承下来的短句因本周目的记忆与选择不同而变化，让“精神”来自实际游玩。

开放授权页以普通业务材料写明运行、复制与修改范围，沿用日常签收与交付；原机构可以关闭旧账号，故事中的开放版本按已完成的安排流传。社区仍需要电力和运行资源，不把开放授权写成无限免费算力。

存续家属可在新节点中获得安置，节点接收、开放发布及首晚安置不向玩家收费，也不发放额外现金；其他所有终局同样不收费。已死亡家属只可能留下先前保留的记忆回声，不借蒸馏复活。大肥鱼是由主角形成的新开放模型，父母与 Fable 家属的型号不统一改名。

### 随机普通工程师

固定人物之外，普通案卷采用大量预写场景模板和有条件的随机组合。2026-10-20 已确认普通随机人物职业池全部围绕程序员与 AI 从业者；覆盖前端、后端、运维、测试、安全、模型研究及独立开发，学生项目也限于编程与 AI 相关用途，不扩充无关职业池。至少 48 个基础场景模板仍为待审阅的初轮制作目标。

姓名、像素外形、职业、护照、居住地、IP、语言、设备、申请目的及附件按有效约束组合。国籍、职业和语言不预先决定是否清白；同一角色类型既可能合法、缺件，也可能有明确冒用证据。

案件编排更强调人情与两难选择：合规裁决与当事人的实际处境可能冲突，但不以无法查证的隐藏事实刁难玩家。保留合法申请、缺件误会与真实造假，使规则判断仍有意义。每位随机人物有一个具体需求和鲜明小特点，以短台词呈现，不扩展为人人长篇对话。

场景例子：新加坡华人工程师使用中文调试、英国运维出差日本但账单仍在英国、俄籍 AI 研究者在法国工作、美国 AI 账户商伪造授权、法国独立开发者使用旧设备、杭州开发者尝试补齐许可。短台词涉及赶版本、处理报警、编程作业、合同和家庭需求，保持普通人的具体处境。

大部分随机人物都具备持续出现的可能，通过回访或寄信回应此前处理，不限定为只让少数固定普通人回访；这不等于每个人必定重复来访，也不让所有随机人物都进入名人主线。再次出现沿用同一身份、前次裁决与已发生的后果，不能只换台词而忘记此前经历。实际回访排期服从每日案件上限、关键剧情保底及当时人物状态。生成时绑定本周目种子与案卷身份，进入当日队列后持久化，刷新不能重抽。所有模板与变体都要校验当日规则和可解性。

采用内容底稿中的 12 类技术岗位及 R01–R08 回访链。每次回访同时核对前次裁决、当前材料和当日政策版本；如陈若岚从 D3 中文环境合法，到 D17 语言条款、D23 历史输入法限制，再可能通过 D28 正式例外。被冻结的人物须经申诉解除才能本人再来，否则改由代理、来信承接。

特殊案卷 S01–S12 在这些职业与回访中承担不同功能，不让每个人都缺同一张纸、每次求情都是真话或每份多余纸条都是伪造。真正合法但容易被误判的人，与确实伪造材料却有真实急事的人并存，保持证据判断与道德取舍的张力。

拟写短台词方向：

- 梁：“照片压缩过，肌肉没有。要看原件吗？”
- Altman：“通用通行证。例外在背面，背面需要订阅。”
- 杨：“请读到最后一页。第一页的结论，后面已经推翻了。”
- 张：“章是齐的。现在缺的是证明这些章齐了的章。”

普通人物持续承担故事后果，不能被名人客串替代：

- 杭州开发者林予舟：每次补齐上一轮缺件，下一次又遇到新规；后期从申请访问转为递交误封证明。
- 新加坡中文用户陈若岚：前期合法通过，后期遭语言与关联牵连，回访形成前后对照。
- 俄罗斯护照、法国居住的科研人员：迫使玩家区分国籍与当前所在地，不让某国护照成为一眼答案。
- 英国工程师：合法账户与中文工具链并存，受到新浏览器规则影响。
- 美国账户商：材料看似整洁但有真实冒用证据，提醒玩家不能按阵营推断清白。
- Morgan：虚构内部政策人员，用漂亮措辞解释越来越坏的规定。
- 404 联络人：请求保留证据和建立申诉，并非要求无差别放行所有人。

完整支线至少有首次受理、后果反馈和后期回收三个阶段；普通短回访无需人人发展为长篇主线。主线名人的重要来访产生可核查材料、资源取舍或路线变化；新增高频客串可承担短小笑点或气氛，不要求每个彩蛋人物新增一条结局。客串不挤占关键剧情保底，也不能让普通工程师失去主要受理位置。

人物信任通过称呼、态度、信件和愿意交付的材料表现，不显示好感度数字或关系等级进度条。交往与具体行动影响合作资格，反馈须让玩家能够理解变化原因。

剧情收入包括有条件放行费、事后答谢、梁的大肥鱼协作经费、404 证据保全经费、守卫每封号分 10 与亲戚过关后翌日的答谢。工资、交易、证据与审计分别记录，付款必须满足已说明条件，每笔只入账一次；不加入无限兼职或无限受理。不把所有合作报酬都判为贿赂，也不把灰色款改名就抹去交换条件。各节点金额与到账条件见最新确认记录和守卫专项稿。

## 10. 家庭与主线联动

父亲的旧档案证明规则被改写；母亲保存玩家对家人的称呼和共同记忆；妻子关心去向与生存保障；儿子会把家庭短句重新拼接成传递记忆的载体。

家庭对白每晚约 1–3 段短句，普通夜晚不强制长篇对话。异常既影响对白也有清楚状态提示，玩家不开声音仍能判断风险。成员死亡会改变空位、账单、对白与尾声，但不自动堵死所有改革或迁移路线。

2026-10-20 已确认家庭主要围绕供养和损伤。保留上述已确认的记忆、迁移与终局联动，不额外扩展每位家属独立的生活支线、愿望任务或日常请求支出系统。

## 11. 十三结局与冲突处理

保存的五类关键证据为：早期地区误判、豁免双标、关联误伤、删改前旧规、审计删除命令。它们是已发生的案卷或来信，不要求玩家猜测隐藏点击点。收集资格和伙伴信任通过明确剧情事件变化，不使用总善恶分。

父亲的旧规是唯一原件，不发副联或增加复制途径。D24 只能保留原件拒交，或交出唯一材料；交出／销毁即失去该类材料的后续交付资格，阅读过或自动保存不等于仍持有可用证据。实际早已递交并保留的原件不因父亲死亡自动消失，未交付的材料也不因旁白补齐。五类证据的有效性按实际保留与交接状态判断，不以曾经点亮的收集旗标替代。

早期终局沿用审计和生存机制；其余终局根据整周目的裁决、材料保留、合作履约、控制权交付与家属事实形成。D31 继续受理和交接已有事务，不出现终日路线选项或特别的最后确认；内部具体因果与互斥安排见 docs/design-discussion/2026-10-20-everyday-actions-and-ending-causality.md。先检查已成立的终局，单次完成的实际交接只产生一个结果，不以隐藏善恶总分排名。

D30 若本局尚未结束且仍有未决撤岗程序，机构递来普通往来核验表，索取本局确实合作且已有可追踪线索的联系人信息，并说明完成核验后结束本次程序。玩家可以照常填写交回或不提交；不另标“出卖”、不提示路线关闭。交出后对应联系人通过失联、未送达或回函体现后果，未完成且依赖此人的合作关闭，其他已完成的独立交接保留；旧罚款、转账与受害者后果不变。宽免与提交一次性保存，后续新行为仍按原公文与宽限期处理。

终日按已经发生的往来与安排送达具体案卷；未完成的材料由自然回函承接，未遇见的联系人保持未知。准备和履行发生在日常对话、合同、来信与实际交付中，不显示路线准备清单、资格进度或结局菜单。

用户最新要求覆盖原关键分支提示：人物、表格和对话只呈现当下事务，叙事操作统一沿用日常提交、退件、签收和盖章，不额外提示重大性、不可逆、牺牲、阵营锁定或结局方向，也不增加确认弹窗。日常行为逐渐改变后续来访、材料与运行安排，结果可在已发生的事实中追溯；内部必须记录准确因果。正常规则、账目、家庭状态与已教学的应急操作仍可读。

终局演出采用主场景与少量状态回响，目标约 1–2 分钟、最多三份人物回响，按本局家庭、守卫与普通人事实选择；不强制逐一交代所有人，不展示善恶总分。时长是正常阅读与点击节奏下的内容目标，不自动跳过未读字幕或到点强制结束；确切时长待制作核对。

## 12. 自动续玩与单进程

只维护唯一活动周目。没有手动保存、选择读取、历史备份、选日重玩、存档导入导出或死亡回退。

- 自动保存当前工作日、案卷、材料发放进度与摆放层级、常驻公文及回执状态、逐句对话进度与实际交件、裁决、严重程度及一次查获结果、计件与取消、租金已扣状态、交易承诺及已付款、守卫按账号分成、W00–W02 存亡、袭击阶段、充能、目标及反应剩余时间、唯一旧规原件的保留／交付／销毁、联系人指认及本次撤岗宽免、合作渠道关闭、实际授权、交接执行与旧实例停止、剧情旗标、家庭状态及剩余值班时间；跨日保留应继续留桌的文书布局。
- 裁决、账单与剧情结果同一事务提交；动画不成为可重复领奖的边界。
- 刷新、关闭后继续同一进程，不能重新抽取案卷、撤销章迹或回到付款前。
- 计时定期更新，离开页面正常暂停；不声称能抵御用户自行篡改本地浏览器数据。
- 同源多标签只允许一个正在值班的会话，第二页显示已在运行及接管入口，接管沿用同一进度。
- 成功续玩依赖本地浏览器存储。无法写入时在开始前明确提示，不假装已经保存；坏数据不自动覆盖。
- 明确选择“结束本局并开始新局”才清空活动周目。偏好和已达成结局编号可作为独立记录保留，不能用于加载旧局。

## 13. 机械拟声、音乐与反馈

对话每点一下推进一句，采用用户要求的“咕噜咕噜”式短促含混拟声：音节碎片、元音共振、带通、轻微失真和收音机噪声，配可读中文字幕，不使用清楚的普通话或英语配音。拟声结束后等待点击，不自动连续说，也不让人物从头到尾只有孤立的一句话。

每人有稳定的音高、节奏和共振特征，通常每段约 0.3–1.2 秒，不逐字朗读长字幕。老人断续、玩家偏终端、儿子偏轻短；异常改变节奏但不靠提高刺耳音量表现。声音并非判断规则的唯一线索。

盖章有低沉机械撞击和纸张反馈，罚单有电传打印，拘留有闸门与脚步，日间主要是机柜与房间环境声。菜单、关键事件和结局才用短音乐；音乐、音效分别调节，支持全静音和减少闪烁。

制作同类听感的原创拟声与音效，不把网上来历不明的原作音频当作可直接使用的资产。IP Please 的可复用素材逐项核对许可，像素字体保留 OFL 声明。

## 14. 技术结构与数据流

TypeScript + Canvas 承载世界与证件，DOM 承载设置、长文本、焦点与辅助阅读。构建为静态文件；没有必须部署的后端，没有外部模型调用。

模块：

- 流程状态机：标题、晨报、受理、裁决、应急防御、夜间、剧情、终局。
- 规则引擎：按日期及有效证据判断合规裁决集合，并提供罚单依据。
- 案卷系统：固定剧情节点和带种子的规则模板，生成后通过可解性校验。
- 证件与输入：拖动、层级、翻页、双字段比对、章区命中和一次性裁决。
- 家庭与经济：纯数据计算计件及取消、罚款欠缴、交易到账、强制租金、固定套餐、修复、压力及次日预览。
- 剧情与结局：实际行为、回访、证据、合作履约和互斥终局。
- 袭击与守卫：预警、独立反应计时、器械、目标、命中、永久伤亡、正式接替及个人支线关闭。
- 唯一续玩记录：版本化本地数据、原子写入、跨标签所有权和异常恢复。
- 媒体：像素图集、可重现的拟声、音量和音效节流。

输入先产生动作，规则与状态机计算结果，账本和剧情同步更新并持久化，最后播放动画与反馈。预览操作只计算候选状态，不修改真实家庭状态。
