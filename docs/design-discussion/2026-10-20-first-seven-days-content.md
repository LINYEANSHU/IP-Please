# 前七天内容底稿：晨报、公文、80 个案位与夜间结算

日期：2026-10-20。状态：按现行确认设定编排的首周内容底稿；具体台词、案卷与排期供后续制作审阅，尚未实现、尚未试玩。新近六项主线与终局决定见 docs/design-discussion/2026-10-20-route-contracts-evidence-and-endings.md。

## 1. 共用规则与阅读方法

- D1 为 8 案，D2–D7 每天 12 案，共 80 个有限案位。下表列出一组固定内容样例；实际生成时仍须服从种子、连续人物状态及既有案位上限，不在这些案位外加工资。
- 主线保底放在当日第一案或班前事件。普通案未赶上不计误判、也不计件；时钟归零可完成已入场的一案，再自然收班。
- 报纸、公文、首次必要教学、气氛事件强制表演和 D7 首袭过场暂停值班时钟；正常翻纸、问话、比对与裁决按既定模式计时。对话逐句点击，每句短促机械拟声，不自动连播。
- 日期使用虚构工作日号。许可标记“1–10”表示 D1 签发、D10 到期，首尾均有效；本稿固定样例的初始有效期不会随是否放行而临时改变。
- 各表的 IP 栏是游戏案卷中的静态地区事实，不读取现实玩家网络。国籍、姓名和实际所在地按其解锁日进入，不能倒用于 D1 的判断。
- 未另注时，已经解锁的基础材料均真实、当前有效且属于本案同一申请人；当日已经要求的许可、主体或绑定一致。表中明确列出的缺口覆盖此默认值。正常允许与正常拒绝均计件 5，不靠拒绝更多人提高普通工资。
- 所有案都有有效盖章载体：D1–2 是 IP 通行册，D3 起是实际交出的护照；“忘记递件”不设为唯一护照缺失而无处盖章。普通拒绝只盖章，封号／拘留和复核均未解锁。
- 每天只公布实际生效的规则页，不发未来目录、全字段表或未解锁工具。早期纸面上的申请编号与以后正式个人身份分开，不在 D1 印出姓名、国籍或设备栏。

本稿的“允许／拒绝”是作者核验用的合规处理，不向玩家显示答案。玩家仍可明知违规允许，按既定轻重、查获与处罚规则处理；人情台词不会自动补齐材料。
