# 政策演进、事件与大幅晨报

日期：2026-10-20。依据：用户要求政策持续变化，从当前 IP 逐步扩大到账号关联、浏览器与输入法，并融入事件；用户同时授权人物、回访、客串等按现有方案推进，要求晨报参考原作的大报纸形式。

本文将这些方向落实为制作设计。工资与固定生活费已由用户明确，见 2026-10-20-dialogue-enforcement-and-pay-decisions.md；新增守卫与上市冲刺见 2026-10-20-guard-commission-and-listing.md。具体文案、修复及剧情报酬初值和整体平衡仍需校验。尚未开始产品实现。

后续用户新增突然袭击、守卫伤亡、增援和紧急防御器械，并授权选择题材。本轮排入 A01–A04 章节事件，日期与具体人物安排属于制作初值，详见 2026-10-20-attacks-defense-and-guard-survival.md；其后果与小事件七三比例分别处理。

## 1. 每天发生什么

每天以同一条因果链组织内容：世界事件或宣传口径变化 → 大幅报纸的头条与短讯 → A÷ 下发可执行的纸质公文 → 当天证件核查出现变化 → 普通人与名人的选择和回访体现后果 → 次日新闻引用已经发生的结果。

政策是持续变化的主线。打印机、队伍、风扇、牌匾等演出结合当天改令安排，不再独立堆放成无关的笑话清单。每次改令都有世界内的说法，玩家通过新字段、旧材料的新解释、例外的改变和人物回访感受到它。

“约 70% 气氛、30% 后果”继续用于随政策发生的小插曲：F 类选择不额外暗扣收入、不改变信任或路线；C 类选择可产生额外后果。当天公布的新规本身会改变所有相关案件的判定，无论玩家是否查看完笑话。这个比例不把每日政策、普通裁决或家庭生存变成可有可无的装饰。

## 2. 早期只按当前 IP 判断地区资格

早期“中国账号管控只看 IP”的含义是：在地区资格这一项，只看本次申请的当前 IP 是否位于游戏支持地区。中国国籍、中国注册账号、中文姓名、中文设备或输入法本身均不额外导致拒绝；护照真假、许可证有效期等基础核查按其解锁日期照常执行。

同一个中国注册账号，早期使用支持地区的当前 IP，其他已生效条件也满足时可以合规通过。后期新规才开始要求注册地区、历史记录、浏览器、输入法等额外材料或牵连依据。人物不能只是今天换一个随机 IP，必须有与其实际经历一致的所在地、材料和变化记录。

所有账号、网络与设备字段仍为虚构案卷数据，不读取玩家真实 IP、浏览器、输入法、手机号或设备。

### 材料也逐日发放，首日只见当前 IP

用户进一步明确：规则、材料与工具必须一起逐步进入游戏。第一天只检查 IP，就只提供 IP 和盖章所必需的东西；后期不断增加纸条和证明，让有限桌面被官僚手续挤满。这是核心体验要求。

D1 仅有最简 IP 通行册、当天支持地区的小纸条和允许／拒绝两枚实体章。通行册保留证件册与盖章页形态，内页只显示当前 IP 及其所属地区、有效盖章区；不提前给姓名国籍资料页、许可证、浏览器、输入法、手机号或完整设备报告。姓名等剧情数据可在内部保持连续，但未成为检查内容前不印到首日材料中。

D2 才递交访问许可证，出现日期、签发及本次申请的对应信息，开始跨纸比对。D3 再引入国别护照与身份资料，原有 IP 材料继续提供当前连接信息；正式护照加入后，裁决盖在护照章区。七国护照的封皮与内页设计保留，但不会在 D1 把所有护照和证据类型一起摆上桌。

手册也从当日已发布的一页规则起步，随后收到新页、修正条和附录。不展示完整 31 天规则、未来字段列表、尚未需要的材料页或一排未解锁工具；每次新规通过晨报、短公文和首个相关案件介绍新增检查，再沿用到后续工作日。

### 从一张材料到满桌文书

下表是制作和试玩的密度目标，不是每案固定配额。复杂案随阶段逐步增多，简单个人案和特殊剧情案按实际需要发材料；常驻文书与当前申请人的材料分别计算。

| 阶段 | 新进入玩家视野的材料 | 申请材料的目标量级 | 桌面变化 |
|---|---|---|---|
| D1 | 最简 IP 通行册、支持地区小纸条 | 1 件申请材料 | 大部分桌面空着，只需看 IP、盖章 |
| D2 | 访问许可证 | 2 件 | 开始在 IP 和许可日期之间来回看 |
| D3 | 国别护照与身份页 | 约 3 件 | 护照、IP 和许可需要并排比对 |
| D4–7 | 绑定凭条、连接核验条、商业委托书，按各自政策日期出现 | 约 3–4 件 | 有效公文和补充纸条开始留在桌边 |
| D8–12 | 照片复核单、海外使用证明、账单附件、复核回执 | 常见 4–6 件 | 材料开始叠压，调查还会吐出补件 |
| D13–16 | 授权链、企业关系折页、历史关联报告 | 复杂案约 5–7 件 | 不同部门重复写主体、日期和编号，需翻查多份纸 |
| D17–19 | 语言配置条、浏览器证明、输入法安装清单，分三天加入 | 复杂案约 6–9 件 | 新规定分别带来新纸条，旧材料继续要查 |
| D20–23 | 特许证、搜索来源单、历史绑定条、卸载及旧配置记录 | 复杂案约 7–10 件 | 例外、历史与当前材料互相遮挡，常驻公文已有多页修正 |
| D24–30 | 旧规回收单、审计问询、申诉回执、专项许可与节点材料 | 个别复杂案可达 8–12 件 | 申请材料叠在常驻公文、修正页和待处理回执之间，满桌压力达到高峰 |
| D31 | 根据实际往来与已经履行的安排取出对应案卷和交接材料 | 延续日常受理与交付 | 之前积累的文书、控制权和记录自然收束，不显示路线／结局选择菜单，不增加新检查系统 |

应急器械同样遵守渐进发放：首日不摆枪柜或充能 UI，D16 拟配发并教学，之后才有可操作救援。配发回执可作为真实常驻小纸条留桌；器械不代替材料比对、不整理桌面。正式流程与武器使用在应急状态切换，不在审查中自动替玩家封号。

不同部门各发各的纸：浏览器证明不会顺手整合输入法检查；输入法安装清单、卸载记录、语言配置和手机号历史可以分别来自不同系统。它们有可识别的版式、签章和编号，并可能重复要求同一主体的信息，以实际跨纸核查表现手续膨胀。新材料在对应规则生效时才发放，不在 D1 印出一张全字段表后逐步点亮。

撤销旧稿“复杂案最多 5 件、设备字段全部集中一张纸”的限制。已有案件上限仍约束每天受理人数，不限制后期单案的纸张增长。不同阶段的材料量级须通过可解性和操作试玩校准，不把上述目标写成已完成平衡的结果。

### 固定小桌面承受增加的手续

桌面尺寸保持原样，不随天数扩大，不增加自动整理或一键汇总。玩家通过原有拖动、叠放、拿到最上层、翻页和折叠纸张腾出位置；盖章仍需要露出实际有效章区。

当天有效公文、补充规定、修正条和待处理回执默认作为实体纸留在桌面，跨日延续其摆放与处理状态；新增公文不会自动把旧公文清空或合并成漂亮摘要。废止条款有废止日期或章记，玩家可主动将其放入已有旧档，不能把旧规当现行规则。当前申请人的原件仍按正常结案流程由玩家退还，不靠无限堆积已办完的无关原件制造噪声。

每一张增加的纸应承担一个真实检查、例外、重复证明或待处理任务。打印机笑话可以产生临时长纸表演，但真正的日常拥挤来自制度持续新增的手续。上级不断要求增加核查，工作台和办事资源却没有相应增加；公告甚至可以称之为“流程简化”。玩家要在这种压力下维持收入、处理人物处境并照顾家人，讽刺通过操作发生。

在材料堆叠时仍保证全部当前证据可取回、章区可露出、同一案件可按已公布规则完成；放大阅读和清晰字体保留。纸张不会无端消失，玩家也不会因设计错误永久够不到某张材料。轻松模式同样经历纸张膨胀，只取消倒计时，不一键收走这份工作负担。

### 本作的大报纸

晨间先出现独立报纸画面，背景压暗，横向纸张占主要阅读区域。采用旧纸、深色油墨、粗细分栏线、大报头、日期期号、主副标题和少量短讯。排版按像素尺度设计，保留纸页边缘；报纸不是叠在桌面上的现代通知弹窗。

刊名暂沿用本地参考中的《安全日报》作为制作名称，机构仍写 A÷。一期建议包含一条主新闻、一条副新闻和两条极短栏目；栏目可围绕算力天气、行业动态、普通人的项目与昨日窗口结果。正文只保留可读的短段，非必要细节可用印刷纹理表现，不强迫阅读满版长文。

报纸下面提供“去上班”入口。读报不计值班时间，可以放大阅读；进入岗亭后，通过已有阅读入口查阅当天报纸。翻页只在重大新闻或额外短讯确有需要时使用，不把每日晨报做成长篇必读流程。

### 桌上的正式公文

到岗后收到独立的 A÷ 纸质公文，明确列出：文号、生效日、今日变化、涉及字段、允许的例外、调查／拒绝／拘留各自条件。同步更新手册，标清新增、修订与废止内容。报纸负责叙事与宣传，公文负责能否裁决；正文口号不能替代裁决依据。

看公文和晨间教学不计值班时间，玩家叫进第一人后才进入当日正常计时。纸质公文与手册仍可在岗亭查阅，不增加可升级工具。

## 5. 后期字段怎样真正改变裁决

以下均为游戏中的虚构扩张条例，不是已证实的现实封禁算法。各案的设备记录由游戏生成、带有日期，与当事人当前和过去的材料一致。

| D16 | 公告范围内有受限地区历史记录 | 历史时间、实际用途和相应证明 | 有合理证据可通过；不足按已解锁流程复核，不凭一个历史标签拘留 |

| D23 | 历史设备记录存在曾安装的关联配置 | 记录版本、发生日期、当前有效例外及历史覆盖范围 | 当前已卸载不自动清除关联；记录不全不得假装已证实，有效例外只在明确覆盖历史项时适用 |

中文、新加坡国籍与 UTC+8 在早期不会触发上述后期条款。后期的语言管制可以误伤新加坡中文用户，但处罚依据必须明确写作新生效的虚构条例，而不是倒称她以前隐瞒国籍。

后期仍配置没有关联命中、持适用许可、材料齐全的可允许案件，也保留真实造假案例，避免整天只需盖拒绝章。材料数量按阶段增长，设备相关证明随各自政策逐步以独立纸张出现；不再使用统一 2–4 件、复杂最多 5 件的限制，也不自动汇总成单张全字段设备表。

## 8. 生效、证据与公平性

1. 每天晨报有日期，正式公文有对应版本与生效范围。新条款在上岗前可读；修改、例外、废止均写明，不要求玩家从宣传口号猜规则。
2. 默认新规从当日首案生效；剧情确需日间紧急通告时，在下一位入场前发布并更新手册，已受理案件沿用入场时版本。通知与强制演出暂停计时。
3. 旧案记录保存原裁决及当时版本。今天可依法重新审查同一账号，但不能把昨天按旧规作出的正确裁决偷偷扣成今日误判。
4. 现有证据分别记录当前事实、历史事实和未知。缺记录不等于事实不存在，风险报告也不自动等于已证实违规；需要补件、复核或拒绝时公文写清对应处理。
5. 特许证和试点许可只豁免列明字段，不能遮掉假护照、实际主体冒用和未覆盖的限制。普通拒绝与拘留冻结保持不同条件。
6. 同一案与同一政策版本有可验证的合规裁决集合。玩家可以自愿违反政策帮助人，明显违规必罚，轻微补充件缺失约五成查获；实际罚单引用明确条款，未查获仍给计件，人物后果另行表现，不用一个善恶分替代。
7. 随机案卷绑定当天规则，回访保留前次经历，再生成新日期的合法材料或真实矛盾；不靠任意打乱字段制造无解组合。
8. 昨日后果可改变次日副新闻或短讯，政策主版本保持可追踪；不会因跳过读报而重抽案件、失去隐蔽路线或吞掉审计期限。
9. 材料与字段的首次出现绑定政策日期：D1 只有 IP，D2 加许可，D3 加护照；未发布内容不以空白栏、未来目录或未解锁工具提前摆出。新规则通过首个相关案例介绍后再增加组合难度。
10. 逐阶段检查桌面从空到满的实际变化，并确认取纸、叠放、翻页和盖章可完成。常驻公文与申请材料分别积累，跨日保留摆放；不通过自动扩桌、自动整理或统一电子摘要消除官僚手续造成的压力。
