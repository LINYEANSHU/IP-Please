- 640×360 世界、三分屏岗亭、独立大幅晨报、V01 公文、8 个有限案位。

- 逐句字幕与原创机械拟声、印章／纸张／罚单反馈、音效与菜单环境音乐开关。
- 唯一自动续玩、完整快照事务、跨标签接管、存储失败暂停重试、坏 JSON／未知版本保留、旧版缺章迹坐标的内存兼容。
