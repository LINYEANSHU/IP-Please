## 双语实现

`src/i18n/en.json` 为本地英文目录。`t()` 仅在显示边界翻译，原有中文事实、案号、动作 ID、状态机比较和存档结构不改。DOM 保留原文引用，切换时恢复或翻译同一文字与辅助名称；Canvas 在宽度适配之前翻译。

语言偏好写入独立键 `ip-please:language`，不替换唯一进度。切换会取消临时手持物，保持已保存案件、余额、时间和剧情。设置、阅读、错误恢复仍沿用原事务。

英文报纸允许三栏独立滚动；护照文字按内页宽度适配；纸张摘要可通过原文入口完整阅读。截图在 1280×720 和 1920×1080 生成，保留于 `docs/readme/`。游戏目标仍是电脑横屏，未宣称移动端完整适配。

## 拖放修复

在 Chromium CDP 合成触摸中，第二手指会覆盖原拖动；另一 pointerId 的取消事件也会清除当前拖动。两个回归用例均先实际失败，再经修复通过。现在只接受未被占用的主指针，取消事件按 pointerId 匹配；释放捕获之前先清空拖动，避免同步丢失捕获事件重复清理。此证据来自桌面 Chromium 合成输入，不代表物理触屏设备验证。

## 证据与限制

README 仅嵌入真实游戏截图；没有合成试玩成绩、下载量或背书。源字符串覆盖不等于每个英文句子都经过母语编辑；纸面摘要仍可能需要原文阅读。浏览器自动化用虚拟时钟检查重复交易和整周流程，不声称玩家一定能在 90 秒内完成 12 案。
