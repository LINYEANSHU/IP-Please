# 底薪与供养调整 · 2026-10-21

用户要求：底薪为 10，全家电力和运行 Token 均为 10。

两种模式每日底薪统一为 10；全家电力、运行 Token 各 10，总价 20。底薪先于租金到账，修复费用保持原值。首页、夜间价格、付款预览、余额不足提示、实际扣款和账本校验使用对应的新金额。

已结算的旧工资和旧供养账目保留原值，不补发或重扣；未结算的底薪、尚未购买的供养使用新金额。新增账目带价格版本，旧版无版本账目按原价校验，避免旧 schema1/schema2 存档因调价失效。读取不覆盖原存档。
